# Proyecto Educativo - Institución Joyfe

## Descripción
Proyecto web desarrollado con fines educativos para la Institución Joyfe, ubicada en Madrid.

## Estructura del Proyecto
```
├── index.html
├── readme.md
└── assets/
    ├── css/
    │   └── sc.css
    └── js/
        └── app.js
```

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Uso
1. Abre `index.html` en tu navegador
2. Los estilos se cargan desde `assets/css/sc.css`
3. La lógica de la aplicación está en `assets/js/app.js`
